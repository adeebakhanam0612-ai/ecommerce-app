Ecommerce App

A full-stack ecommerce web application built using React, Node.js, Express.js, and MongoDB.

Features

- Create Orders
- View Orders
- Delete Orders
- MongoDB Database Integration
- REST API Backend
- React Frontend
- Real-time UI Updates

Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- Axios

Project Structure

ecommerce-app/
│
├── backend/
└── frontend/

Installation

Backend

cd backend
npm install
npm start

Frontend

cd frontend
npm install
npm start

API Endpoints

Create Order

POST /api/order/create

Get Orders

GET /api/order/myorders

Delete Order

DELETE /api/order/delete/:id
